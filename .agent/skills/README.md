# Skills / Profiles

Skills are Devland **Profiles**: focused specialist guidance loaded only when the current change triggers it.

A skill is justified when:

- the concern recurs across multiple changes
- domain-specific failure modes are easy to forget
- loading the guidance improves decisions without becoming global policy

A skill must state its trigger and remain narrower than `rules.md` / `system-design.md`.

Do not create skills for speculative roadmap items or duplicate generic engineering advice. If a capability becomes a current product concern later, add the smallest profile then.
